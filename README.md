# গেস নম্বর গেম | Guess Number Game

![Game Preview](https://img.shields.io/badge/Status-Active-brightgreen)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![License](https://img.shields.io/badge/License-MIT-orange)

**গেস নম্বর** হলো একটি মজার ও ইন্টারেক্টিভ নম্বর গেসিং গেম। ইউজার 0 থেকে 4 এর মধ্যে নম্বর গেস করে, আর সিস্টেম র‍্যান্ডমভাবে একটি নম্বর জেনারেট করে। যদি ম্যাচ করে তাহলে জয়, না করলে হার।

## 🎮 গেম কিভাবে খেলবেন

1. **গেম সেটআপ**:
   - "রাউন্ড সংখ্যা" নির্বাচন করুন (1 থেকে 20 এর মধ্যে)
   - "গেম শুরু করুন" বাটনে ক্লিক করুন

2. **নম্বর গেস করুন**:
   - 0 থেকে 4 এর মধ্যে কোনো একটি নম্বর নির্বাচন করুন
   - অথবা টাইপ করে "জমা দিন" বাটনে ক্লিক করুন
   - বা কিবোর্ড থেকে Enter চাপুন

3. **ফলাফল দেখুন**:
   - সঠিক গেস করলে জয় গণনা হবে
   - ভুল গেস করলে হার গণনা হবে এবং সঠিক নম্বর দেখাবে

4. **গেম শেষ**:
   - সব রাউন্ড শেষ হলে স্বয়ংক্রিয়ভাবে গেম শেষ হবে
   - "গেম শেষ করুন" বাটনে ক্লিক করেও গেম শেষ করা যাবে

5. **স্কোর সেভ করুন**:
   - গেম শেষ হলে "স্কোর সেভ করুন" বাটনে ক্লিক করুন
   - আপনার স্কোর হিস্টরিতে সেভ হয়ে যাবে

## 🎯 গেম রুলস

1. প্রতিটি রাউন্ডে 0 থেকে 4 এর মধ্যে একটি নম্বর গেস করতে হবে
2. সিস্টেম র‍্যান্ডমভাবে একটি নম্বর জেনারেট করবে
3. যদি আপনার গেস এবং সিস্টেমের নম্বর ম্যাচ করে তাহলে জয়
4. যদি না ম্যাচ করে তাহলে হার
5. গেম শেষ হলে মোট জয় এবং হার দেখাবে

## 🔒 ভ্যালিডেশন

- কেবল 0-4 নম্বর গ্রহণ করে

- নম্বর বাটন ক্লিক করেও নির্বাচন করা যায়
- ভুল ইনপুট দিলে এরর মেসেজ দেখাবে
