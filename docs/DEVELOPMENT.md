# ডেভেলপমেন্ট গাইড | Development Guide

## 📋 প্রজেক্ট ওভারভিউ

এটি একটি সিম্পল কিন্তু পাওয়ারফুল নম্বর গেসিং গেম। পুরো প্রজেক্টটি HTML, CSS, এবং Vanilla JavaScript দিয়ে তৈরি।

- কোনো টুল ইনস্টল করার দরকার নেই!

## 🎮 গেম লজিক

### স্টেট ম্যানেজমেন্ট

```javascript
const gameState = {
    totalRounds: 0,      // মোট রাউন্ড
    currentRound: 0,     // বর্তমান রাউন্ড
    wins: 0,             // জয় সংখ্যা
    loses: 0,            // হার সংখ্যা
    isGameRunning: false,// গেম রানিং কিনা
    currentGuess: null,  // বর্তমান গেস
    generatedNumber: null// জেনারেটেড নম্বর
};
```

### মূল ফাংশনসমূহ

1. **generateRandomNumber(min, max)** - র‍্যান্ডম নম্বর জেনারেট
2. **isValidGuess(value)** - ইনপুট ভ্যালিডেশন
3. **startGame()** - গেম শুরু
4. **nextRound()** - পরের রাউন্ড
5. **handleGuess()** - গেস হ্যান্ডেল
6. **endGame()** - গেম শেষ
7. **saveScore()** - স্কোর সেভ

## 🔧 কাস্টমাইজেশন

### গেম সেটিংস পরিবর্তন

`app.js` ফাইলে:

```javascript
// র‍্যান্ডম নম্বর রেঞ্জ পরিবর্তন
function generateRandomNumber(min = 0, max = 4) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}

// ম্যাক্স রাউন্ড পরিবর্তন
// index.html এ gameRounds ইনপুটের max অ্যাট্রিবিউট পরিবর্তন করুন
```

### থিম কালার পরিবর্তন

`style.css` ফাইলে CSS Variables পরিবর্তন করুন:

```css
:root {
    --primary-color: #4a6fa5;  /* এইটা পরিবর্তন করুন */
    --success-color: #2ecc71;
    /* ... */
}
```
